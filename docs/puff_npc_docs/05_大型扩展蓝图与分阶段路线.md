# 帕芙（Puff）—— 大型扩展蓝图与分阶段路线（阶段 5 ~ 阶段 8）

> **前置条件**：请先完成 **阶段 4**（车万女仆风格基础面板 + 8 幕剧情 JSON 闭环）并提交 Git 存档后，再按本手册顺序逐关推进 **阶段 5 → 6 → 7 → 8**。

## 阶段 5：复活与收纳 + 本体养成 + 动态 Curios + 属性面板

### 设计要点
1. **双通道复活 & 便携收纳（1C + 2B）**
   * **「鼠灵奶酪核」**：帕芙死亡时在原地掉落一枚防火、防爆炸、防仙人掌、免疫虚空（虚空死亡时直接悬浮传送回主人安全坐标或主世界出生点附近）的特殊物品，完整保存帕芙全部 NBT（好感、阶段、服装、剧情、小窝、属性、饰品）。
   * **「黄金奶酪温巢」方块**：Rats 题材复活祭坛。放入奶酪核并投入 `rats:cheese`（或 `blue_cheese`），伴随暖金粒子几秒后满血复活帕芙，并弹出专属重逢台词。
   * **「鼠灵铃铛 / 怀表」**：
     * 空手或绑定状态下右键帕芙：将帕芙收纳进物品（Tooltip 显示名字、阶段、服装、当前血量与好感）；
     * 右键地面：放出帕芙；
     * 走丢时右键空气：一键把同维度/跨维度的帕芙召回身边；
     * 若帕芙死亡且持有绑定的铃铛：手持它右键任意奶酪块并消耗一块奶酪，直接原地招魂复活！
   * **主人防误伤开关**：在面板新增「主人防误伤保护」开关（默认开启）。
2. **移植 `Rats: Reboot` 本体养成（神奇糖果 + 基因酥）与实时属性面板**
   * 在 `PuffEntity` 上实现类似 Rats 本体的基础属性成长、区间上限与品质系统：使用本体 **神奇糖果** 提升当前属性数值，使用 **基因酥** 拓宽属性成长区间。
   * 在类车万女仆面板新增 **「属性面板」标签页**（类似玩家背包旁的属性页），实时展示所有计算后属性（含装备、糖果/基因酥、Curios 饰品、以及 `ApothicAttributes / attributeslib` 注册的暴击率、暴击伤害、护甲穿透、吸血、治疗加成等特殊属性，若装了 ApothicAttributes 则自动读取并应用其属性修饰）。
3. **动态 Curios 饰品栏（数量自适应算法）**
   * 统计当前整合包中所有已注册物品里属于各 Curios 槽位类型的饰品总数 $N$：
     * 若 $N \le 3$：为帕芙分配 **3 个**该类型槽位；
     * 若 $N > 3$：按 **`Math.round(N * 0.8)`** 动态计算槽位数（并设合理上限防止 UI 溢出，如单类最多 12~16 格，支持滚动条）。
   * 面板新增 **「饰品栏」标签页**，装备后全部 `AttributeModifier` 实时生效在帕芙身上。
4. **`PuffFakePlayer` 基础架构（让外部模组识别帕芙为玩家）**
   * 为每只帕芙分配固定派生 UUID（由帕芙实体 UUID 派生，确保每次一致）并构建轻量 `ServerPlayer` / `FakePlayer` 代理，同步主手/副手/护甲/Curios 状态，为部分只认 `Player` 的饰品效果及后续 Lootr 开箱、施法提供统一代理。

## 阶段 6：大姐头权杖 + 鼠群逐只派工 + 无限挖矿/蓝图 + Lootr 开箱 + RS 护符

### 设计要点
1. **「大姐头奶酪权杖」（右键天空切换模式）**
   * **手持右键天空（空气）**：弹出奶油樱粉风格的 **权杖模式轮盘/选择菜单**，切换 3 种右键功能：
     1. `设置范围坐标`（右键两个对角方块框选工作区、或右键指定箱子/原矿/蓝图原点）
     2. `老鼠进入团队`（右键属于主人的 `TamedRat`，将其编入帕芙直属小队）
     3. `老鼠离开团队`（右键已入队老鼠移出小队）
2. **面板「鼠群调度」标签页（逐只分配工种 + 联动本体升级组件）**
   * 列表显示小队中每只小老鼠的名字、当前持有的 Rats 本体工作升级组件、当前工种，支持**逐只独立指派以下工种**：
     * **砍树**（自动砍伐范围内树木并种回树苗）
     * **无限挖矿（诡厄巫法风格 · 4B）**：老鼠对着范围内任意原矿方块（兼容 `#forge:ores` 全部模组矿物）持续挖掘，**原矿方块不消失**，按矿物稀有度定期消耗少量奶酪（来自帕芙小窝或绑定的补给箱）源源不断产出对应矿物掉落物！
     * **机械动力蓝图建造（软依赖 `create`）**：帕芙面板提供「蓝图槽」，放入 `create:schematic` 并设好原点与材料箱后，小队老鼠从材料箱取料逐块建造。
     * **自动耕作**（收割成熟作物、补种并存箱）
     * **自动钓鱼**（靠近水源自动钓鱼，收获存入小窝或指定箱子，帕芙偶尔吐槽鱼干）
     * **基地巡逻清怪**（在设定范围内巡逻击杀敌对生物）
     * **牧场照料**（使用箱中繁殖食物喂养动物、剪羊毛、收蛋）
   * 若老鼠本身装有 Rats 本体的对应工作升级（如伐木/采矿/厨师/农夫升级等），则大幅提升该工种效率与产出速度。
3. **帕芙本人专属工种：Lootr 战利品箱第二份开箱**
   * 软依赖 `lootr`：当玩家开启「帕芙自动搜刮附近宝箱」指令时，帕芙走到附近未开过的 `Lootr` 战利品箱旁，使用 `PuffFakePlayer`（独立 UUID）合法触发一次开箱，为团队多拿一份战利品存入自己的秘密小窝！（若没装 Lootr 或普通箱子则跳过已空箱）。
4. **帕芙专属饰品：「RS 共振存物护符」**
   * 仿照 `Rats-Reboot` 内置的 `rat_upgrade_rsi_courier` 实现：
   * 玩家 **Shift + 右键** Refined Storage 的终端/控制器绑定坐标；
   * **普通右键**打开护符的 9~18 格过滤 UI，支持切换 **白名单 / 黑名单** 模式；
   * 将护符装备到帕芙的 Curios 护符槽后，帕芙在工作与囤积期间会自动把小窝里符合规则的物品直接存入已绑定的 RS 网络！

## 阶段 8：动态场景对话 + 可视化剧情树 UI + 三结局分支与回溯

### 设计要点
1. **动态场景对话（「聊聊眼前的事」）**
   * 在 Galgame 底部对话框中保留经典「回忆话题」，新增更核心的 **「聊聊眼前的事」** 按钮：
     * 服务端采集帕芙当前上下文标签（维度、群系温度/类型、晴/雨/雷暴、清晨/正午/黄昏/深夜、10 格内特殊方块如奶酪/篝火/床/箱子/矿石、附近打工中的老鼠、主人手持物品、刚结束战斗等）；
     * 按上下文匹配语言库中对应的丰富情境台词（数据驱动 JSON），每次点击优先聊当前最贴景的话题；
     * 到达全新群系或维度时，有低频率主动在帕芙头旁冒出轻巧小气泡搭话。
2. **可视化剧情树 UI 页面（Flowchart）**
   * 在管理面板新增 **「剧情路线图」标签页**：以树状节点 + 连线展示全主线、支线与三条结局分支：
     * **已完成节点**：樱花粉高亮，点击可直接重看；
     * **可触发/下一节点**：暖琥珀金呼吸边框，悬停或选中时**明确显示触发条件**（好感度、阶段、需要去的群系/维度、需要准备的道具）；
     * **未解锁远期节点**：锁定态，提示前置节点。
3. **三结局分支与「结局回溯」机制**
   * 在第三章之后分出三条正式结局路线（均可走 `PuffStory` 数据驱动）：
     * **结局 A · 《纯白花嫁与永恒小窝》（True End · 恋爱结婚线）**：满好感求婚 → 穿婚纱结婚，改口「亲爱的」，解锁婚后清晨彩蛋。
     * **结局 B · 《鼠特兰蒂斯双星》（传奇搭档 End · 冒险女王线）**：征服鼠特兰蒂斯与末地 + 鼠群小队达标，在终末抉择中选择“永远做并肩闯天涯的最强搭档” → 穿星光礼装获得专属战斗并肩光环。
     * **结局 C · 《奶酪与麦浪的田园诗》（田园工坊 End · 悠闲同居线）**：在主世界建起一定规模鼠群工坊（完成多次派工与奶酪储备），选择“把荒野变成永远温暖的奶酪田园” → 解锁家园生产增益光环。
   * **结局回溯机制**：达成任意结局后，剧情树上该分支节点旁边会出现「**回溯至分支点**」按钮，允许玩家在保留全部已解锁服装和图鉴的前提下，重新体验另外两条结局路线并收集全结局徽章！
