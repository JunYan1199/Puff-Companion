# 帕芙（Puff）—— 人设与阶段设定总纲

> **适用环境**：Minecraft（NeoForge）× `Rats` 模组原创陪伴型 NPC

## 二、身世背景与生态定位

### 1. 创世初遇：世界赠予的“初始鼠灵”
帕芙没有苦大仇深的过往——她是这片新生的方块世界送给冒险者的第一份礼物。  
当新世界刚刚生成、玩家第一次睁开眼站在出生点的阳光下时，旁边那丛随风晃动的草叶里就钻出了一颗毛茸茸的白色小脑袋。她抖了抖沾着露水的圆耳朵，琥珀色的眼睛直勾勾地盯着你，理直气壮地宣布自己是“今天起负责罩着你的搭档”。

她天生能听懂这片大地的风声与矿脉的脉动，也能听懂所有小老鼠的语言，唯独对“人类是怎么在方块世界里生活、盖房子、打怪和做美食的”充满无穷好奇。她的成长，就是陪着玩家把荒野一点点变成家的过程。

### 2. 鼠群定位：说一不二的“大姐头”
在 `Rats` 模组的普通老鼠面前，帕芙气场一米八，是公认的**鼠群小队长 / 大姐头**。  
哪只老鼠偷懒摸鱼、哪只负责搬运奶酪、哪只去收割小麦和分类箱子，她叉起腰指挥两句就能井井有条。不过这种威严往往只能维持到“奶酪出炉”或“猫路过”为止。

## 三、性格内核与四大核心反差萌

1. **表层性格：机灵元气小管家**  
   花枝鼠的高智商全点在了“照顾玩家”和“操心家务”上。精力永远满满当当，嘴甜又话多：会替你记住箱子分类、会在黄昏催你回家睡觉、会一边碎碎念“别老空手撸石头啦”，一边把刚采的甜浆果塞进你手里。
2. **反差 ①：俏皮讨赏派 × 摸头当机体质**  
   干活从不含糊，但收工后一定会尾巴一晃一晃地凑上来讨工资：“这波收成全靠本队长英明调度！双倍陈年奶酪，或者……摸头三下抵债！”  
   可一旦玩家真的顺手揉了她的圆耳朵、挠了她的下巴，或很认真地夸她一句“有你真好”，她就会瞬间失去全部语言能力，耳尖红透、眼神乱飘、支支吾吾原地当机。
3. **反差 ②：极度怕饿 × 奶酪理智清零**  
   只要饱食度见底，她就会变成蔫巴巴、说话有气无力的“没电鼠”。平时聪明伶俐，但只要空气里飘来融化奶酪或陈年奶酪的香味，理智立刻清零，瞳孔放大、尾巴笔直，哪怕一秒前还在严肃布置战术也会当场倒戈。
4. **反差 ③：遇猫秒怂（血脉压制）**  
   哪怕到大后期已经敢提着神装陪玩家闯下界、战末影龙、进军鼠特兰蒂斯，只要在村庄撞见流浪猫、在丛林听见豹猫叫，或是玩家自己驯养的猫多看了她两眼，她还是会“吱！”一声炸毛躲到玩家身后，揪着你的衣角小声抗议。

## 四、花枝鼠习性与玩法机制映射

| 花枝鼠习性 | 游戏内交互与玩法表现 |
| :--- | :--- |
| **隐秘囤积癖（秘密小窝）** | 帕芙会偷偷捡起玩家没注意或丢弃的“闪亮小垃圾”（铜粒、铁粒、荧石粉、玻璃片、多余种子、奶酪边角料），搬回自己的专属小窝/储物点摆整齐。被抓包时会脸红辩解：“这是战略储备！以后盖大房子用得上！” |
| **高浓度粘人精** | 只要没在干活，绝不肯离玩家超过三格。平时喜欢拽着衣角跟在后面，休息时会自然地靠过来贴贴，甚至缩身/凑近钻进袖子或稳稳坐在玩家肩膀上晃悠小脚。 |
| **雷达级听觉与嗅觉（生存预警）** | 下矿或探险时，帕芙的耳朵会先一步竖起，提前预警墙后苦力怕的嘶嘶声、矿洞深处的僵尸低吼，或是隔着石头闻到地牢刷怪笼与战利品宝箱的气味。 |
| **开心磨牙信号** | 当好感度提升、吃到极品奶酪或被温柔顺毛时，会触发轻微的“咔哒咔哒”磨牙音效与冒爱心粒子。 |

### 五套阶段服装详细设定（纯文本设定，供建模/换装系统参照）

1. **【前期冒险服】**（阶段一解锁）
   * **风格**：轻便耐脏的森系新手冒险装。
   * **细节**：米白色亚麻短袖内搭，外穿焦糖色帆布背带短裤（预留尾巴孔），肩上披着带一圈毛绒小边的浅棕短斗篷；腰间挂着鼓鼓囊囊的皮革小腰包（一半塞火把与种子，一半塞应急小奶酪）和一只迷你木质水壶，脚穿系带短靴，整体显得娇小灵动、朝气蓬勃。
2. **【中期精致药师/工匠服】**（阶段二解锁）
   * **风格**：融合炼金药师与机械工匠美感的干练套装。
   * **细节**：白粉配色修身衬衣外搭深褐与暖金滚边的半身工匠围裙/束腰马甲；头侧或胸前挂着迷你黄铜护目镜，腰侧挂一串彩色微型药水瓶；袖口挽起方便干活，腰带整齐别着小扳手、羽毛笔、记事本与老鼠指挥笛，下摆点缀小齿轮与奶酪块刺绣，既专业又保留少女俏皮感。
3. **【后期精美服装】**（阶段三解锁）
   * **风格**：华丽而轻盈的终末冒险礼装（融入鼠特兰蒂斯古代遗韵与星光感）。
   * **细节**：以象牙白、樱花粉与琥珀金为主调的层次感礼服短裙，搭配半透明星纱披肩与精致金丝镶边；发间点缀小型金色冠饰或奶酪星芒发卡，胸口有发光宝石吊坠与轻巧魔导纹路；既透出“鼠群女王 / 大冒险家”的可靠气场，又不失灵动轻快的少女感。
4. **【泳衣】**（海滩 / 暖水海洋群系支线解锁）
   * **风格**：元气清凉的夏日少女泳装。
   * **细节**：奶白色与樱桃粉撞色的荷叶边分体/连体式泳衣，衣面点缀暖黄色小雏菊与迷你三角奶酪印花，胸口与腰侧系有轻盈蝴蝶结；搭配一顶特意留出两个圆耳朵穿孔的宽檐草帽与透明果冻感凉鞋，阳光下能看到俏皮晃动的粉色尾巴。
5. **【婚纱】**（终章求婚剧情解锁）
   * **风格**：圣洁梦幻的少女花嫁礼服。
   * **细节**：纯白缎面与多层轻盈欧根纱交织的蓬蓬短拖尾婚纱，裙摆与头纱边缘缀满细腻的淡樱粉花瓣刺绣与暖金色小珍珠（呼应白粉发色与琥珀金瞳）；头纱上方特意留出鼠耳穿孔并在耳根系着迷你白纱蝴蝶结，腰后垂落大号轻纱蝴蝶结并自然留出尾巴的活动空间。

## 六、与 `toneko` 模组无 API 本地交互架构对照

为避免依赖外部大模型 API，帕芙的全部互动均通过以下**三层纯本地机制**在 `toneko-neoforge-2.0.3` 架构下完整呈现：

| 交互层级 | 对应 `toneko` 模块 | 帕芙文档落地点 | 玩家体验 |
| :--- | :--- | :--- | :--- |
| **第一层：剧情演出** | 内置 Galgame 引擎 `org.cneko.gal`（`PlotParser` / `DialogueScreen`） | `02_主线与支线剧情脚本.md` | 在特定进度、地点或好感节点触发，弹出立绘/角色聚焦对话框与多分支选项，推进关系与解锁服装/称呼。 |
| **第二层：主动菜单** | 右键实体交互面板 `InteractionScreen`（按钮 + 固定话题树 + 送礼） | `03_交互菜单与事件触发对话库.md`（第二部分） | 玩家随时右键帕芙可点击“聊天话题”“赠送礼物”“跟随/坐肩/摸头/换装/指挥鼠群”等按钮获得即时固定反馈。 |
| **第三层：动态气泡与聊天** | 本地事件触发器 + `NekoBubbleRenderer` / 聊天栏播报 | `03_交互菜单与事件触发对话库.md`（第三~五部分） | 无需任何 AI，根据 MC 世界事件（矿洞怪物、天黑、下雨、遇猫、饥饿、见奶酪、老鼠收工等）自动随机抽取对应台词池在头顶冒泡或聊天栏提示。 |
