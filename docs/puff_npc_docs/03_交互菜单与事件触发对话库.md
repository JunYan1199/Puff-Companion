# 帕芙（Puff）—— 交互菜单与事件触发对话库（无 API 本地方案）

> **设计说明**：本文档专为 `toneko-neoforge-2.0.3` 的本地交互机制设计，**完全不需要任何外部 AI API**。  
> **通用变量约定**：
> * `{player}`：玩家角色名
> * `{call}`：自动称呼变量（阶段一=`{player}`，阶段二/三=`哥哥`或`姐姐`，阶段四=`亲爱的`）
> * `{item}`：玩家送出或帕芙捡起的物品名

## 二、右键交互菜单（`InteractionScreen`）固定对话库

### 1. 固定话题树（点击“聊天”按钮展开）

> 按好感/阶段逐步解锁新话题，类似 `Crystal_Neko` 的本地多页话题交互。

* **话题 1：【关于你自己】**（初始解锁）
  * **帕芙**：「我是帕芙！一只刚好在你出生那天从草丛里钻出来的花枝鼠灵！别看我平时只到你肩膀附近，我的听力和嗅觉可是全方块世界顶级的哦！」
* **话题 2：【关于其他小老鼠】**（初始解锁）
  * **帕芙**：「你是说 Rats 模组里那些整天跑来跑去的小家伙吗？它们超听我话的！只要我吹一下哨子，搬奶酪、收麦子、整理箱子全都能排着队搞定。不过……它们脑子没我好使，还是得靠本队长盯着！」
* **话题 3：【关于秘密小窝】**（完成第一章后解锁）
  * **帕芙**：「喂！都说了那不是捡破烂，那是战略物资库！铜粒、发光粉尘、好看的羽毛和备用的奶酪角，每一件我都摆得整整齐齐……好吧，{call}要是哪天缺小东西用了，可以来我这里借一点点。」
* **话题 4：【关于天敌（猫）】**（触发支线一后解锁）
  * **帕芙**：「哼！我才不是怕那些长胡子的家伙，我那是……那是战略性避险！谁知道它们心里是不是在偷偷打我尾巴的主意呀！总之，{call}不许夸它们比我可爱，听见没！」
* **话题 5：【关于我们的未来】**（进入阶段三后解锁）
  * **帕芙**：「以前总觉得能盖个不漏雨的小木屋就够厉害了，现在跟着{call}走过那么多地方……不管以后要去多远、多危险的世界，只要回头还能看见你，我就什么都不怕啦。」
